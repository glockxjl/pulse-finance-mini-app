## Функционал основной объединённой версии

1. **Обзор и аналитика (Светлое Бенто):**
   - Динамический заголовок периода и разделение итогов: отдельно `Доходы`, `Расходы` и `Итог (Д−Р)` за выбранный период (`7Д` / `МЕС` / `ВСЕ` / произвольные даты) и отдельно справочный итог по всем учтённым операциям в базе (с пометкой, что это оценка по записям, а не баланс банка).
   - Прозрачная оценка дневного лимита («Можно тратить сегодня») строго по текущему календарному месяцу (`Доходы мес. − Расходы мес. − Копилка − Неоплаченные счета мес. ÷ Оставшиеся дни месяца`), не зависящая от выбранного фильтра истории; автоматический сброс отметок об оплате счетов при наступлении нового месяца.
   - Кольцевая SVG-диаграмма расходов по категориям с фильтром по клику, график по дням недели и карточка финансового здоровья (норма сбережений).
2. **Операции и быстрый ввод (сервер D1 как единственный источник правды в LIVE):**
   - Умная строка быстрого ввода чека (`Lidl 14.80`, `+ 500 Аванс`) с мгновенным определением категории и типа операции.
   - Полная карточка просмотра, редактирования (`✏️`), дублирования (`📋`), возврата доли 50/50 и быстрого удаления (`×`) операции.
   - Все изменения в режиме LIVE (`create`, `update`, `delete`, `bulk_import`) применяются к интерфейсу только после подтверждения Cloudflare Worker + D1, с защитой от повторного нажатия и идемпотентным `externalId` при повторе после сбоя сети.
3. **Авто-категоризация (расширенный словарь Литвы и ЕС + самообучение):**
   - Распознавание более 75 мерчантов Литвы (`Lidl`, `Maxima`, `Iki`, `Rimi`, `Norfa`, `Šilas`, `Aibė`, `Assorti`, `Wolt`, `Bolt`, `Subway`, `Čili`, `Huracan`, `Caif`, `Crustum`, `Ignitis`, `Telia`, `Bitė`, `Tele2`, `Cgates`, `JUDU`, `Trafi`, `Unipark`, `Stova`, `Circle K`, `Viada`, `Neste`, `Emsi`, `Orlen`, `Eurovaistinė`, `Camelia`, `Benu`, `Gintarinė`, `Apotheka`, `Kardiolita`, `Antėja`, `Senukai`, `Ermitažas`, `Ikea`, `Depo`, `Jysk`, `Pepco`, `Pigu`, `Varlė`, `Topocentras`, `Vinted`, `Zalando`, `About You`, `Forum Cinemas`, `Multikino`, `Akropolis`, `Ozas`, `Panorama`, `Swedbank` и др.) с защитой коротких ключей (`iki`) по границам слов.
   - Самообучающийся словарь в `localStorage` при ручной смене категории пользователем.
4. **Импорт/экспорт данных:**
   - Атомарный импорт CSV выписок Swedbank через D1 `batch()` с предвалидацией строк и дедупликацией по банковскому `externalId`, экспорт в CSV.
5. **Безопасный клиент API и честный статус связи:**
   - Авторизация только через подписанный заголовок `X-Telegram-Init-Data` (`Telegram.WebApp.initData`) без тестовых обходов проверки подписи.
   - Раздельные статусы подключения в шапке и баннере: `DEMO`, `Подключение…`, `Синхр. HH:MM`, `Нет связи • кэш` (с явной пометкой сохранённой копии) и `Нужен вход TG`.

## Статус серверного API и интеграций

- **Серверный бэкенд:** полностью переведён на Cloudflare Workers + D1 (`pulse-api.dragonfantom2007.workers.dev`), поддерживает `list`, `create`, `update`, `delete` и `bulk_import`.
- **Авторизация Mini App:** валидация HMAC-SHA256 подписи `Telegram.WebApp.initData` и проверка `userId === 1604405483`.
- **Честный индикатор связи:** зелёный статус `Синхр. HH:MM` включается только после реального успешного ответа Worker; при сбое сети отображается `Нет связи • кэш` с предупреждением о сохранённой копии.
- **Прямой приём оплат из iOS Shortcuts (Apple Pay):** серверный маршрут `POST /api/shortcut` реализован в Worker (с ключом `X-Shortcut-Key`, дедупликацией и записью в `transactions`), однако клиентская автоматика iPhone Shortcut в iOS на данный момент **отложена**, и сквозной сценарий не принят (локальная кнопка симуляции в приложении работает только в режиме `DEMO`).
- **Кнопка меню в боте:** настроена через `@BotFather` (`/setmenubutton`) на адрес GitHub Pages.

## Как запустить локально

1. Открой файл `index.html` в любом браузере — по умолчанию включён **Демо-режим**, который работает автономно через `localStorage` без запросов к серверу.
2. Для проверки с данными из n8n открой приложение внутри Telegram и переключи режим в верхней панели или во вкладке **Настройки** на **API (Тест)**.
