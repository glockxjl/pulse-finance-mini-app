# PULSE — Telegram Mini App & Finance Bot

Персональное приложение для учёта личных финансов в евро (€) внутри Telegram (Mini App + Telegram Bot на базе n8n Cloud).

## Структура проекта

```text
finance-mini-app/
├── index.html                  # Интерфейс Telegram Mini App (Обзор, Операции, Аналитика, Настройки)
├── styles.css                  # Стили и темы Telegram WebApp (26 КБ)
├── app.js                      # Логика, словарь магазинов Литвы, демо-режим и клиент n8n API (71 КБ)
├── CHATGPT_PROJECT_PROMPT.md   # Готовый промпт и паспорт проекта для загрузки в ChatGPT Plus Projects
├── README.md                   # Это описание
└── docs/                       # Архив документации и контекста
    ├── CHATGPT_CONTEXT.md      # Личный контекст и предпочтения
    ├── PROJECT_FINANCE.md      # Аудит n8n, правила безопасности и история разработки
    ├── PLAN.md                 # Технический план, формулы и схема таблиц n8n
    └── GEMINI.md               # Рабочие правила для ИИ-агентов
```

## Как запустить локально

1. Открой файл `index.html` в любом браузере (по умолчанию включён **Демо-режим**, который работает автономно через `localStorage` без запросов к серверу).
2. Для проверки с данными из n8n переключи режим в верхней панели или в вкладке **Настройки** на **API (Тест)**.
